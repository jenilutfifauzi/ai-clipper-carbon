# 04 — Transcript, Words, Cues, and caption editing on Android

Type: grilling
Status: open
Blocked by: 02, 06

## Question

How should native captions obtain their timing and remain in sync with the server's `Preview Plan`? Decide whether the Android editor must display and edit the Candidate's transcript-derived `Words`, `Cue` boundaries, per-word highlight spans, `Word Edits`, and `Cue Edits` directly, or whether any native-only/manual-caption mode is an acceptable separate workflow.

Specify the behavior when source words are unavailable, a media item's transcription is pending or fails, a Cue crosses a trim/split, and a server Revision changes during editing. Confirm whether phrase/sentence line limits, caption presets, position/animation, SRT/VTT, and subtitle-only export are parity requirements for the first caption milestone. The current manual-caption slice is not evidence that these behaviors are complete.
