# 08 — Project persistence, library, templates, and export settings

Type: grilling
Status: open
Blocked by: 02

## Question

What must survive app restarts and device changes, and where is it stored? Decide the project/library lifecycle for source video, downloaded Job media, rendered outputs, transcript, edits, asset files, Template and Style Preset references, plus cleanup, storage limits, and recovery after interrupted renders.

Specify which existing Template, Channel Profile, Style Preset, and Export Preset workflows are mobile parity requirements; what export controls are offered initially (resolution, aspect, codec, frame rate, quality, loudness); and whether users can choose device storage versus S3-compatible storage for outputs. The current local-render result is temporary until the user saves it to the gallery and has no persistent project model.
