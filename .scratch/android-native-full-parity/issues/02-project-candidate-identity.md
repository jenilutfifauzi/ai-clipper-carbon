# 02 — Project identity and Candidate handoff

Type: grilling
Status: open

## Question

What is the canonical editable object in the native app: a saved mobile Project that can optionally link to a server Candidate, or the existing server Candidate/Revision for every edit? Decide how a gallery video with no Job/Candidate is represented, whether edits synchronize across web and phone, and which operations require upload. Keep a phone-gallery render local unless the owner explicitly starts an upload-dependent AI workflow.

The answer must identify the owner of source media, edits, and rendered outputs; the stable identity used when returning to a project; and what happens when a Candidate's server Revision changes while the phone has unsaved edits.
